# متجر — المشروع الكامل (Frontend + Backend)

الفولدر ده فيه مشروعين لازم يشتغلوا مع بعض:

- **store-app-angular/** — الموقع (اللي المستخدم بيشوفه)
- **store-app-backend/** — السيرفر + قاعدة البيانات + تسجيل الدخول

## ابدأ من هنا

اقرأ `store-app-backend/README.md` الأول — فيه شرح كامل من الصفر لكل حاجة (إيه هو
الـ backend، إيه هي الـ database، إزاي شغّال تسجيل الدخول، ومشاكل شائعة وحلولها) +
خطوات التشغيل.

## ⚠️ مهم جداً قبل ما تشغّل حاجة

ملف `.env` (بتاع الباك إند) **متبعتش معاك في الزيب ده عن قصد** — لازم تعمله انت بنفسك
وتحط فيه كلمة سر ومفتاح سري خاصين بيك. القيم اللي تحطها موجودة في رسالة Claude في
المحادثة (متكتوبتش في أي ملف من ملفات المشروع لأسباب أمان).

## تشغيل سريع (تلخيص)

```bash
# Terminal 1 — شغّل السيرفر
cd store-app-backend
npm install
cp .env.example .env
# افتح .env وحط القيم اللي اديتهالك في المحادثة
npm start

# Terminal 2 — شغّل الموقع
cd store-app-angular
npm install
ng serve -o
```

لازم الاتنين يفضلوا شغالين في نفس الوقت في نافذتين منفصلتين.
